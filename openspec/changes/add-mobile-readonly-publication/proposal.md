## Why

搬迁负责人需要在自己手机浏览器上只读查看最新业务进展（概览、搬迁项目搜索/列表、详情与关联业务记录），但桌面 SQLite 仍是唯一业务权威与唯一写入方，且仓库当前零网络能力（无 `fetch`/`node:http`/`node:https` 引用）。本 change 引入**默认离线、仅由负责人显式启用的必要字段白名单只读发布**与独立的手机只读入口，不改动桌面无密码直接进入等既有行为，也不恢复 HEAD 3477864 已整体撤销的复杂远程方案。

## What Changes

- 桌面端只读发布（默认关闭、显式启用）：主进程从本机 SQLite 的**单一一致事务**内遍历全部搬迁项目与全部六类关联记录（有界分页逐页收集，非首屏），按**设计文档白名单契约**（封闭字段表）提取只读快照，全量替换上传。停用即停止后续检查与上传。
- 变化检测与周期：应用启动检查一次、运行且联网时约每 2 分钟检查；以 `contentGenerationId`（恢复/代际轮换）与 `businessRevision`（同代际内增长）作为"与上次已发布候选是否不同"的指纹，任一不同才发布。无写入不上传，桌面如实标记"最近发布/最后成功时间"而不伪称实时。
- 上传与一致性：发布端 single-flight（同一时刻仅一个进行中候选）；上传协议与业务快照**分层**（`protocol` 携带 `publicationId`/`expectedCurrentVersion`，`snapshot` 为业务白名单快照）；`expectedCurrentVersion` 条件替换（服务端仅比较相等才提交）；上传有限超时；失败记录规范化错误码（不保存任意服务响应/网络内容）并在下一周期重试，不阻断本地。上传成功后保存的是**候选捕获时的指纹**，不重新读取上传完成时刻的最新修订（期间新写入归下一轮）。
- 云端轻量只读服务（单 Node 进程 + 文件包络，无数据库/Redis/队列）：唯一权威文件 `current.json` = `{currentVersion, publicationId, publishedAt, snapshot}`，一次原子 rename 提交；启动读文件恢复，内存仅缓存，从未提交无文件无版本 0；校验（snapshot 封闭白名单含嵌套未知 key 拒绝、金额/日期格式、`expectedCurrentVersion`、`publicationId`）后原子替换；**幂等仅对当前存储 `publicationId` 生效**（重复当前 ID 返回成功且不改版本/publishedAt；更早候选按冲突处理，无历史库）；冲突/响应丢失由上传凭证读取**非业务版本元数据**端点恢复（明确返回当前 `publicationId`），上传凭证不能读业务数据。
- 首次未发布与合法空快照分离：首次允许空快照；已发布后数据清空或恢复空库必须发布**空集合**（空快照是合法发布）；手机页面区分"尚未发布"与"已发布但无数据"。
- 云端有界读取（不上送整份 JSON）：服务端按搜索/筛选/分页向手机提供概览、项目列表、详情与每类关联记录端点；所有业务响应携带当前发布版本；详情等后续请求若发现版本已变，明确提示丢弃旧结果并重新加载。
- 手机只读入口：概览、搬迁项目搜索/列表、详情与关联业务记录；页面打开、切回前台、联网恢复时立即检查版本（不受定时频率限制），前台可见且网络正常时定时检查的相邻触发间隔不超过 60 秒；展示**数据截至时间**（快照建立时间）、**publishedAt**（发布完成时间）与 **lastCheckedAt**（最近成功检查时间，失败不推进）；派生的阶段天数/到期分类按快照时刻状态展示，不伪称实时。断网时内存中已展示内容保留并提示；完整刷新/重新打开且断网则无法加载（`no-store`、无离线缓存）——电脑断网与手机断网语义分开。5 分钟可见预算（声明支持数据规模与正常网络）＝本地变化检查 ≤120 秒 + 手机侧检查 ≤60 秒 + 生成/上传提交/取数/渲染合计 ≤120 秒，E2E 以自动定时触发驱动并在手机页面 DOM 断言新值，不依赖手动刷新或切前后台。
- 凭证与安全：上传 token 由主进程 OS 安全存储保管，不可用即禁用发布（不静默明文降级）；一次性受信配置入口只写 HTTPS 目标与 token 且不回显，IPC 不返回任何 secret；服务端持久化查看密码与上传 token 的**摘要**而非明文；HTTPS Basic Auth 可终止于反向代理，上传端点校验独立 token 摘要，不做模糊的双层 Basic；固定 HTTPS 目标、正常校验证书、禁止自动重定向。
- 金额语义统一：金额内部为分整数（BigInt），经主进程金额格式函数（`formatCents`）输出为**主单位固定两位小数字符串**（如 `"1234.57"`）；可空金额字段未填写为 `null`，允许负值的展示字段保留负号两位小数字符串（如 `"-12.34"`）。快照与手机链路直接复用已格式化的 DTO 字符串，禁止在发布/手机侧再次除以 100 或转 Number（`formatCents` 自身的分→主单位格式化除外）。测试覆盖超安全整数、0、空值与允许负值字段。
- 明确不做：手机写入（不含业务写入表单，允许搜索输入）、多用户、审计历史、附件、报表导出、数据管理、VPN/私有组网、云主库、双向同步、离线业务缓存、原始数据库/Excel 上传。默认不上传联系人、详细地址、自由备注、来源审计、账号/凭证、本机路径与无关敏感字段。

## Capabilities

### New Capabilities
- `mobile-readonly-publication`: 桌面主进程侧受控只读发布 —— 显式启用的封闭白名单快照生成、single-flight 与幂等上传、变化检测与周期、上传超时与失败可见、凭证 OS 安全存储与一次性配置、快照指纹捕获（不读取上传后最新修订）。
- `mobile-readonly-service`: 云端轻量只读服务契约 —— 文件包络 `current.json`（版本/`publicationId`/`publishedAt`/快照一次原子替换、启动读文件恢复、无版本 0）、条件替换 + 仅当前 `publicationId` 幂等、版本元数据端点（仅上传凭证可读、明确返回当前 `publicationId`、非业务数据）、有界搜索/筛选/分页读取端点、业务响应携带版本与 `dataAsOf`/`publishedAt`、空快照合法与首次未发布状态区分、`no-store`、请求体限制、凭证摘要存储。
- `mobile-readonly-workbench`: 手机浏览器只读工作台 —— 概览、项目搜索/列表、详情与关联业务记录；打开/回前台/联网恢复立即查版本 + 前台可见且网络正常时定时检查相邻触发间隔不超过 60 秒；数据截至时间/publishedAt/lastCheckedAt 语义；断网区分内存保留与刷新不可载；无任何业务写入表单。

### Modified Capabilities
- `local-data-persistence`: 将"不向远程发送业务数据"改为默认离线 + 仅负责人显式启用白名单只读发布的最小 delta；本机 SQLite 仍是唯一业务权威与唯一写入方；上传失败与结果状态不可写不影响本地核心业务，启用/目标配置损坏则禁用外发。
- `workbench-access`: 桌面无应用内访问门槛与本地身份模型不变；仅新增独立 HTTPS 只读通道与独立上传凭证，不引入第二个本地账号/角色。
- `workbench-interface`: 桌面提供非干扰的发布启用/停用、一次性配置与状态入口（configured/最近成功/最近失败），不含业务编辑能力；手机只读视图不进入桌面任务指挥台结构。

## Impact

- 桌面主进程新增 `mobile-readonly` 发布模块（配置/快照/调度/上传/状态）；复用 `WorkbenchReadRepository` 的分页方法在单事务内全量收集；不引入网络到领域层/渲染层。新增 IPC：状态读取仅暴露 configured 与最近结果，不返回 secret。
- 手机只读入口为独立 web（区别于桌面单体 `workbench-v2.tsx`，不依赖 `window.workbench`），经云端有界读取端点取数。
- 云端：单 Node 进程 + `snapshots/current.json`（原子替换）+ 内部监听。部署闸门：公网安全组、`workbench.michaelli.site` A 记录（8.162.13.22，TTL 10 分钟）、1Panel 反代新站点独立 LE 证书、OpenResty 容器到内部服务（8082 为待检查候选）网络可达性、预上线阶段仅用子域名定向解析测试且不动既有 `michaelli.site`/`www`。部署时逐项实际验收，不在此 change 承诺。
- `verify:matrix` 仍只扫正式基线 `openspec/specs/`，本 change delta 由 `openspec validate --strict` 独立验证。
