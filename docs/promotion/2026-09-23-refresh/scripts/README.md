# 宣传物料自动化截图生成指引

本目录包含为搬迁服务工作台宣传材料（如朋友圈物料）准备的高清真实应用截图生成脚本。

---

## 1. 脚本定位与数据合规原则

- **全新虚构演示数据**：
  - 核心展示项目统一添加“（演示示例）”显著标识（如“华东精准医疗实验中心（演示示例）”），即使图片离开上下文也能明确识别为虚构演练数据；
  - 物流承运商采用标准通用代称（如“演示物流A（温控专运）”、“演示物流B（气垫专车）”），不借用、不关联任何真实商业品牌；
  - 严格禁止读取客户真实 xlsx/pptx 敏感数据，所有生成数据均经由主进程领域模型完整校验并原子入库。
- **真实构建与渲染**：
  - 桌面端直接运行由 `npm run e2e:build` 打包产出的真实 Electron 应用；
  - 移动端通过 `dist/mobile-readonly/server.cjs` 启动真实只读服务，由 Chromium 模拟 iPhone 视口查阅；
  - 绝无任何前端页面 Mock 或伪造 DOM。

## 2. 产出截图清单

截图均保存至 [screenshots/](../screenshots/) 目录：

## 3. 一键重现命令

在项目根目录下依次执行：

```bash
# 1. 确保打包产物最新（若已有可跳过）
npm run e2e:build

# 2. 确保移动只读端构建产物最新（若已有可跳过）
npm run build:mobile-readonly

# 3. 执行自动化截图脚本（生成全部截图）
NODE_PATH=./node_modules node docs/promotion/2026-09-23-refresh/scripts/generate-promotion-screenshots.cjs

# 或仅重跑特定截图（例如 02 与 04）
NODE_PATH=./node_modules node docs/promotion/2026-09-23-refresh/scripts/generate-promotion-screenshots.cjs --only=02,04
```
